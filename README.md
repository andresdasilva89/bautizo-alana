# Bautizo de Alana Da Silva

Invitación interactiva para teléfono, con apertura de sobre y música instrumental.

- Publicada: https://andresdasilva89.github.io/bautizo-alana/
- Página: `docs/alana/index.html`.
- Entrada del enlace corto: `docs/index.html`.
- Recursos: tres imágenes, `fonts/ananda-personal-use.ttf` y `audio/canon-in-d-major.mp3`.
- Crédito musical: `docs/alana/audio/CREDITS.txt` y el pie de la invitación.
- Publicación: `.github/workflows/deploy-alana-pages.yml`, al enviar cambios a `main`.

No necesita React ni dependencias de Node. Para vista local: `python -m http.server 3032 --directory docs`; abrir `http://localhost:3032/alana/`.

El proyecto de XV años de Deimari está separado: https://github.com/andresdasilva89/invitacion-deimari

## Música conservada

`docs/alana/audio/canon-in-d-major.mp3` es la música actual y se conserva para poder volver a ella si se elige otra canción. Las nuevas pistas deben tener otro nombre de archivo.
